📌 About This Website

This portfolio is basically a digital version of me — my background, skills, experience, and the things I’m passionate about in tech.
I wanted something minimal, easy to navigate, and responsive across devices. Whether someone is a recruiter, a teammate, or just curious, this website gives a quick overview of what I do.

HTML5
CSS3
JavaScript
Bootstrap / Custom CSS
